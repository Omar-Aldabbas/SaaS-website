# SaaS Website

[![Live Demo](https://img.shields.io/badge/Live%20Demo-View-blue?style=for-the-badge&logo=github)](https://Omar-Aldabbas.github.io/SaaS-website/)

A modern SaaS landing page built with **React**, **Vite**, and **TailwindCSS**, featuring sections for Products, FAQ, Blog, and Signup. Designed for analytics and cloud services.

---

## Features

- Fully responsive design
- Smooth scrolling to sections
- Dark/light theme toggle
- Signup/Login pages
- Product cards with ratings
- FAQ page with detailed content
- Blog and About pages
- Hero section with interactive icons using Intersection Observer

---

## Tech Stack

- **React 19**  
- **Vite**  
- **TailwindCSS**  
- **React Router v7**  
- **Lucide Icons**  
- **gh-pages** for deployment
